blurssism
시작하기 팔레트 브랜드북 GitHub

웹과 앱 어디에나 쓰는 디자인 시스템이에요. 우유 거품 같은 바탕 위에 젖빛 크레마 블러레마(Blurema)를 필요한 곳에만 띄우고, 색은 카페인에서 가져왔어요. 유리 표현은 Apple Liquid Glass와 Samsung One UI에서 영감을 받았습니다.
A web & app design system that combines glassmorphism with blur — with caffeine-inspired palettes, a responsive grid, and React & Svelte components.

시작하기 브랜드북 읽기

팔레트와 배경을 고르면 이 페이지와 아래 미리보기가 모두 바뀌어요. Pick a palette and background — the page and every preview follow.

npm install @caffeinecatkr/blurssism
